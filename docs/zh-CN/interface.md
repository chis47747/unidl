> 配色与布局规范均由 UniDL 自身的终端界面定义。

# 终端界面

[English](../interface.md) | [简体中文](interface.md)

一次完整会话由四个核心页面承载：首页、服务菜单、服务流程页与交付页。设置、搜索、上架查询与 CDM 选择器则作为浮层叠加在这条序列之上。

## 主界面

```
   esc Quit                                             ^f Search  ^s Settings
   UNIDL
   cdm samsung_l3 · drm Widevine · after picking download · ready · import · schedule

   SERVICES  available services
     1  BBC iPlayer

   platform name, or its number, or a video URL
   enter open  ↑↓←→ move  d after picking  ^f search  ^s settings  ^r dev reload
```

主界面只回答一个问题——选择哪个平台——因此只展示平台名称及对应的编号。除此之外不堆砌其他信息：不显示账号状态、功能开关或外部助手状态。那些信息属于各个服务自己的页面，把它们移出主界面意味着绘制首页时无需逐一探测每个已注册的服务。

三种等价的选择方式：

* 点击平台名称
* 输入名称的一部分，然后按 `enter`
* 输入平台编号，然后按 `enter`

主界面上列出的全部是 unidl 服务；因为只有这一类对象，所以只保留一个分区。

开启全局调试模式（Debug）后，按 `ctrl+r` 可显式重载当前高亮的服务、输入框中精确指定的 ID/编号，或搜索筛选后仅剩的一项服务。重载范围涵盖其已加载的多文件服务包及原生共享服务依赖，不启动后台文件监视器。随后界面会从注册表重建网格单元，使下一次服务会话生效为新代码。该操作仅存在于页面栈底层，绝不会替换运行中的服务、下载、许可证或播放会话。

### 响应式网格

网格列数根据真实终端宽度动态重算，宽窗口可以一次展示更多平台。实测在 118 列宽下显示 5 列，在 64 列宽下显示 2 列。底部快捷键栏同样按整项裁剪提示，而不会在词语中间生硬截断。

### 实验版搜索首页（Beta Home）

关于以搜索优先替代经典平台网格的可选首页，请参阅[实验版搜索首页（Beta Home）](home-interface.md)。可在**界面与诊断 → 实验主页（Beta）**中开启；上述经典首页仍为默认选项。

## 服务界面

选定平台后会清空主界面并将控制权移交给该服务，由它呈现自身的功能选项：

```
   ^b Back  esc Quit                                     ^f Search  ^s Settings
   BBC iPlayer  ·  anonymous  ·  widevine-test
   ^s after picking download the file  ·  quality best available  ·  choose tracks myself

     1  VOD - open a URL or content ID
     2  Live TV
     3  Search
     4  Settings
  enter confirm  space toggle  ^b back  ^l log  ^s settings  ^p commands
```

页头写明当前登录身份与所使用的 CDM。账号名在展示前统一由 UI 层截断脱敏，而非交由各服务自行处理，确保不会有服务意外泄露完整账号。

选项列表根据服务声明的入口自动生成，并与主界面一样带连续编号，因此直接输入编号即可选择。

下方为日志面板，未写入内容前保持隐藏，按 `ctrl+l` 可展开查看。

## 流程界面与交付界面

流程界面承载从选定服务操作到生成播放信息之间的全部交互：登录提示、选季、选集、直播频道以及解析进度。一旦生成了 `Playback` 对象，即进入交付界面：展示标题、输出文件名、manifest、密钥、已选轨道以及可选的服务/API 章节信息，随后执行下载或保存命令。1 到 3 个章节会直接显示在详情卡片中，点击 `Chapters` 控件可打开完整的可滚动章节时间线，而不挤占进度区或日志区空间。服务级设置中的**轨道与输出 → 将章节写入最终文件**开关仅控制是否把这些章节封装进最终的 MKV/MP4 容器，不会隐藏或丢弃界面展示及导出文件中保存的章节元数据。同一分组下的**字幕输出**控制已选字幕是混流进主文件、在音视频混流的同时另存为外置独立文件，还是跳过下载。选择多个标题时，会自动加入队列，具体行为见 [batch.md](batch.md)。

当**轨道选择**设为自动模式时，由**输出范围**决定哪些媒体类型参与输出：**普通封装**保留视频、音频和字幕；**仅视频**、**仅音频**、**仅字幕**和**自定义**则面向定向输出批次。**最佳一条**为每种类型保留排名最高的一条匹配轨道，**全部匹配轨道**则保留通过该类型过滤条件的全部轨道。定向输出范围不会把所选轨道混流成一个文件，每条输出都会生成带轨道标识的独立文件名。单标题无匹配轨道时可回退至手动选轨器；批量任务则会把该标题标记为跳过并继续处理后续项。

导入可移植导出文件同样会进入这一交付界面和队列。导入时会先匹配服务 ID（包括服务声明的历史旧 ID）：匹配成功则启用已安装服务的上下文，使自定义下载准备、密钥格式化、附属文件及播放生命周期钩子照常生效；未匹配则走通用交付路径，因此播放标准 manifest 时并不强制要求安装原服务包。导出文件本身仍提供 manifest、请求头和内容密钥；通用路径在缺少密钥时绝不会回退发起新的许可证请求。

导出文件中的 `keys` 列表为空本身并不构成错误。未加密的 DASH/HLS 和直链媒体本就无需解密；标准 HLS `AES-128` 由原生下载器根据播放列表中的密钥 URI（配合导出的请求头）自动拉取；由服务预先解析好的原始 AES-128 密钥也会保留在导出文件的 DRM 字段中。仅当播放声明了绑定许可证的 DRM（如 Widevine 或 PlayReady）且解析出的轨道阶梯包含加密轨道时，完全缺失导出的 `KID:key` 才是致命错误。若导出文件只包含部分 KID，Core 会报告未被覆盖的清单，只有 KID 已被覆盖的已选加密轨道可以完成交付。存在已安装服务时，以该服务原有的自定义路径为准；通用回退路径绝不会尝试重新获取缺失的许可证密钥。

### 原生交付进度

执行下载或录制期间，结构化的交付进度会绘制在交付页中央的卡片中并原地刷新——行结构、配色和进度条与独立的 `unidl download` 命令完全一致。每条轨道占一行，批量任务上方还会显示队列整体进展。

过去这些进度曾直接输出在日志里，但这并非刻意设计。嵌入式后端现已改为发射强类型进度事件，不再输出 ANSI 刷新帧或逐次打印日志行，从而让日志回归本职：只记录消息、已选轨道、输出路径和错误。

### 跳到最底部

可滚动的轨道选择器、已选轨道详情、批量队列和日志面板在下方仍有未显示内容时，会在视口底部显示一个小 `▼` 标记。点击即可一步跳到该面板末尾，不会改动轨道选择，也不会启动下载；滚动到底部后该标记自动消失。在日志面板中，点击它还会清除日志内的文本选中状态，并恢复自动跟随新消息滚动。

## 顶栏（Chrome）

每个页面的相同位置都有同一条顶栏；首页处于页面栈底，因此省略“返回”：

| 位置 | 操作 | 主快捷键 | 备选键 |
|------|------|----------|--------|
| 左上 | 返回上一级 | `ctrl+b` | `b` |
| 左上 | 退出 | `esc` | `ctrl+q` |
| 右上 | 搜索 | `ctrl+f` | `/` |
| 右上 | 设置 | `ctrl+s` | `s` |

顶栏展示的每一项都同时支持鼠标点击和键盘快捷键。

### 为什么使用控制组合键

获得焦点的文本输入框会吞掉普通字母键，按下 `s` 只会输入字母 `s` 而不会打开设置。控制组合键则始终直达应用程序，单字母键只是在非输入状态下的快捷方式。不使用 `ctrl+k`，因为 Textual 的 `Input` 已将其绑定为删除至行尾。

### 退出需要按两次

`esc` 是全局绑定键，单次误触绝不能中断进行中的下载会话。首次按下会进入待确认状态并给出提示，1.5 秒内再按一次才会真正退出。

## 作用域划分

“搜索”和“设置”的含义随当前所在位置而变，这是有意为之，用于保证每个页面只聚焦一个问题。

| | 主界面 | 服务内部 |
|---|---|---|
| **搜索** | 服务、片名、上架情况以及整个密钥库 | 仅当前服务的密钥 |
| **设置** | 选定后操作、调试模式、批量确认等全局设置 | 当前服务的专属选项与轨道偏好 |

服务设置仅作用于该服务本身。例如 BBC 的源分辨率与直播地区选项不会影响全局轨道设置。详见 [settings.md](settings.md)。

## 导航层级

| 所在位置 | 按下 `ctrl+b` 的效果 |
|----------|----------------------|
| 主界面 | 清空筛选词；若已为空则无操作（处于页面栈底） |
| 流程内部 | 上退一级提问：分集 → 分季 → 服务菜单 |
| 流程内部（等待下一步提示期间） | 提示服务仍在处理中，并留在当前页 |
| 流程因报错中止后 | 离开该服务，返回主界面 |
| 服务顶层菜单 | 离开该服务，返回主界面 |
| 设置、搜索 | 关闭浮层并返回调用页 |

“流程因报错中止后”与“服务顶层菜单”这两行之所以结果相同，原因也是一致的：抛出异常的流程会连同服务菜单一起结束（菜单本身就是该生成器），底层已经没有可退回的菜单，因此返回只能离开服务而非上退一级。过去因为没有待响应的提问就拒绝返回，曾导致登录失败后页面卡死、无路可退。

页面通过实现 `go_back() -> bool` 接入返回机制：返回 `True` 表示已在页内处理，返回 `False` 表示由栈控制器出栈。服务流程代码无需关心这些细节——`Service.home()` 会捕获子流程抛出的 `Back` 并重新显示菜单。

## 选择操作

| 按键 | 操作 |
|------|------|
| `↑ ↓ ← →` | 移动光标，在网格中支持二维移动 |
| `enter` | 确认 |
| `space` | 在多选列表中切换勾选 |
| `a` / `n` / `i` | 全选 / 清空 / 反选 |
| `Tab` | 切入多选列表筛选框（支持文本或集合表达式，如 `S02`、`S01E05-S02E03`、`3-8,-5`、`13-`、`all`） |
| 数字键 | 跳转到对应编号 |
| `home` / `end` | 跳到首项 / 末项 |
| `ctrl+r` | 在首页且开启调试模式时，重载显式选中的服务代码 |

多选列表打开时会先按自动规则勾选默认项，因此直接按 `enter` 即可采纳。轨道选择器正是以此方式，在进入时预先勾选出轨道偏好匹配的结果。右上角提示行会合并显示已选数量与紧凑序号范围（如 `已选 2 / 27  #2, #4`）。

## 命令面板与快捷键速查

- 按 `ctrl+p` 打开可搜索的命令面板，覆盖全局操作（包括**定时下载**、**添加密钥**、**设置**、**切换主题**和**快捷键速查**）以及所有已注册服务。
- 按 `?` 打开与当前页面上下文对应的快捷键速查弹窗。
- 在设置页面中，按 `m` 可切换**仅看已修改（Modified only）**筛选，快速检查偏离默认值的配置。
- 在定时下载、即将上映雷达和 JustWatch 页面中，按 `p` 可切换右侧的 2:3 海报预览与元数据检查栏。
- 所有维护与诊断功能在 TUI 中均同时提供鼠标点击按钮与键盘快捷键：
  - **就绪检查**：点击顶栏**安装工具**或按 `i`，打开显式确认工具安装弹窗。
  - **设置 → 代理与 VPN**：点击**查看出口 IP**或按 `i`，查看实时出口 IP、地区、时区与运营商（按 `c` 复制）。
  - **设置 → 服务 → Git 服务仓库**：通过底部操作按钮或 `a` / `e` / `Space` / `d` / `r` / `f` 完成添加、编辑、启停、删除、拉取更新与强制刷新。
  - **设置 → 服务 → Firefox Cookie 导入**（以及单服务 **Cookie 配置** 选择器中的**从 Firefox 提取…**按钮 / `f`）：直接在 TUI 中提取 Firefox Cookie 并可选检查 `localStorage`。

## 配色与外观

**设置 → 界面与诊断**提供七套内置主题：`Dark`（默认）、`Light`、`Tokyo Night`、`Catppuccin Mocha`、`Nord`、`Gruvbox` 和 `High Contrast`。你还可以自定义系统配色（9 种预设）、首页标题颜色（12 种渐变/纯色预设）、界面密度（`Auto`、`Comfortable`、`Compact`）以及状态语义色（`Default` 或色盲友好的 Okabe–Ito）。所有外观选择器均支持移动高亮即实时预览，按 `Enter` 或点击**应用**保存，按 `Esc` 还原。按 `ctrl+t` 可在深色与浅色主题间快速切换。

默认 Dark 主题角色配色：

| 语义用途 | 色值 |
|----------|------|
| 强调色、快捷键、已选值 | `#bb9af7` |
| 主文本 | `#e1e1e1` |
| 次要文本 | `#c8c8c8` |
| 弱化文字、提示 | `#6c6c6c` |
| 最弱元素、结构线条 | `#414141` |
| 成功（ok） | `#9ece6a` |
| 警告（warning） | `#e0af68` |
| 错误（error） | `#f7768e` |

布局遵循项目统一约定：上下 1 行内边距，左右 2 列内边距，不使用嵌套方框。

## 无终端环境下的页面渲染

UniDL 在专项冒烟测试中使用 Textual 的无头 `pilot` 驱动页面渲染；当前代码库不包含面向生产环境的快照脚本或覆盖全服务的测试夹具。
