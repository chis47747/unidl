# 外部工具（Helper）

[English](../external-helpers.md) | [简体中文](external-helpers.md)

外部工具（Helper）是指原生服务显式声明的外部依赖。所有解析逻辑均集中在 `unidl.core.helpers` 中统一处理；服务代码不得自行扫描宿主机任意目录，也不得内嵌用户的绝对路径。

服务可声明证书、二进制程序或模块等可选外部工具，例如：

| 外部工具 | 类型 | 用途 |
|---|---|---|
| `helpers/bbc/iplayer.pem` | asset | BBC UHD media-selector 客户端证书 |
| `PATH` 中的 `curl` | binary | BBC UHD 选择器传输工具 |

当某项可选依赖缺失时，服务应在开始播放前明确报告降级模式，而不要在下载进行到一半时突然失败。

## 解析规则

对于已声明的外部工具，UniDL 仅按以下顺序检查显式指定的路径：

1. 当前所选 YAML 中针对该服务的单独覆盖配置；
2. 共享外部工具覆盖配置；
3. 系统 `PATH`（仅限声明为 `binary` 的可执行程序）；
4. `<paths.home>/helpers/<service>/`；
5. 依赖声明中自带的包内资源。

解析过程绝不会递归搜索开发者的文件系统。与具体机器绑定的可执行文件和私有资源应放在版本控制之外；提交到仓库的配置和文档中只应使用相对路径或有文档说明的占位符。

体积较小的公开资源可以作为包数据打包，并通过 `importlib.resources` 加载。私有证书、令牌、设备身份文件和体积较大的原生运行时则应存放在已加入忽略列表的运行时 helper 目录中。
