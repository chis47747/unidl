# 实验版搜索首页（Beta Home）

[English](../home-interface.md) | [简体中文](home-interface.md)

经典的平台列表首页仍然是默认选项。如需试用搜索优先的新布局，请打开**设置 → 界面与诊断 → 实验主页（Beta）**并将其启用。变更会在返回首页时生效，不会替换正在运行的服务会话、下载任务或弹窗。在同一位置关闭即可切回经典首页，偏好设置会跨重启持久化保存。

在**设置 → 界面与诊断 → 实验主页自动结果类型**中，可以勾选**自动（Auto）**模式要搜索和展示的结果类别：服务、导出文件、本地密钥库密钥、设置、JustWatch、服务内搜索以及链接匹配。默认全部勾选。取消勾选某个类别后，会自动隐藏对应结果及其自动操作/快捷行；被禁用的本地密钥库、导出文件和设置源在自动模式下输入时不会被查询。你也可以取消全部勾选，空选择会被保留而不会自动重置为默认全选。

该偏好仅作用于实验版搜索首页（Beta Home）的**自动（Auto）**模式，不会从菜单中移除任何搜索模式，也不会禁用对应的斜杠命令：例如取消勾选密钥库后，手动选择**搜索密钥库**或输入 `/vault` 仍可查看实时本地结果并使用显式的远程搜索操作；取消勾选链接匹配后，自动模式不再打开粘贴的 URL，可改选**打开链接**或**使用指定服务打开**。自动模式中的导出文件路径导入遵循“导出文件”复选框状态，而显式的**打开链接**和**搜索导出文件**保留原有导入行为。经典首页、全局搜索、手动添加密钥和远程密钥库策略均不受影响。

UniDL 横幅以及 CDM、DRM、选定后操作、就绪状态、导入和定时下载控件均保持不变。实验布局将常驻的服务网格替换为单个带边框的搜索栏和本地结果列表。在自动模式下，每条结果前都会带有一个简短的分类标签，例如 **[服务]**、**[导出]**、**[密钥库]**、**[设置]**、**[JustWatch]**、**[服务内搜索]** 或 **[链接]**。每个分类使用各自克制且自适应主题的配色，标题本身保持正常样式。标签随界面语言变化，确保颜色不是区分结果的唯一手段。切换到具体搜索模式后不再重复显示分类标签，公用的**加载更多**控件也没有分类标签。模式标签、输入框和提交按钮排列在同一水平行；标题和键盘提示位于搜索栏外部。查询为空时页面保持留白，不显示空的结果面板。可见搜索栏高度占 3 个终端行，控件和输入文本精确位于正中间一行。常规尺寸窗口会在边框外增加 1 行间距，而非在框内使用不均等的内边距；较矮窗口则会去掉这行额外间距，为搜索结果腾出空间。搜索栏、标题、提示和结果列表与可见的 CDM 至导入状态栏左右边缘对齐，宽度随状态变化和窗口缩放动态调整，而非固定上限；窄窗口则会充分利用可用宽度，保证输入框和操作按钮可用。

当输入框非空时，右侧会出现一个小型 **×** 按钮。点击它或按 `ctrl+u` 可以清空整段输入，同时保留当前模式和已选服务范围。该按钮占有固定预留位，显示或隐藏都不会导致输入框或**前往**（Go）按钮跳动。较长文本会在输入框内部横向滚动。

当焦点在输入框且内容已经为空时，按 `backspace` 或 `delete` 会清除当前模式及其已选服务，退回到自动模式。删除最后一个字符时仅删除该字符，再按一次才会重置模式。点击 **×** 或按 `ctrl+u` 始终只清空文本。其他模式各自记住的服务范围不会被重置。

输入框最多接受 65,536 个字符。任何会导致超出上限的输入都会被拒绝并弹出提示，同时保留原有内容，绝不静默截断签名 URL。在**自动**或**打开链接**模式下，长度超过 4,096 个字符的 HTTP(S) URL 会提供**使用指定服务打开**选项，而不在 UI 线程上运行自动服务匹配器；选定服务后，完整未修改的 URL 会直接传递给对应处理函数。显式的**使用指定服务打开**模式同样支持这类超长 URL。

## 选择搜索模式

点击输入框左侧的模式标签，或在空输入框中键入 `/` 即可打开模式选择器。使用鼠标或方向键配合 Enter 选择模式，按 Escape 关闭选择器且不会退出 UniDL。模式选择器和服务选择器按内容自适应尺寸弹出，始终保持在终端可视区域内，选项过多时支持滚动。服务选择器采用紧凑的 52 列卡片布局，包含单行名称/ID 筛选框，最多同时展示 8 个服务；通过筛选或滚动可访问全部服务，且筛选过程中卡片尺寸保持稳定。小窗口下卡片会自动收缩以适配可用空间。

| 模式 | 功能说明 |
|------|----------|
| 自动（Auto） | 自动识别受支持的 URL、已存在的导出 JSON 路径或 KID/密钥查询。其他文本则展示匹配的主页可见服务、本地导出文件、设置项以及显式的片名搜索动作，包括根据关键词前后的服务名或简称推断出的服务内搜索。 |
| 搜索服务 | 按主页可见服务的名称、ID 和别名进行搜索。精确且无歧义的名称可直接按 Enter 打开。 |
| JustWatch | 提交片名后，使用已配置的搜索地区和上架查询地区打开既有的 JustWatch 搜索页面。 |
| 服务内搜索 | 先选择一个声明支持搜索的已注册服务，再提交片名。走该服务自带的搜索流程，而非 JustWatch。 |
| 打开链接 | 仅将 URL 路由到声明支持该链接的已注册服务；同时支持粘贴导出 JSON 路径。 |
| 使用指定服务打开 | 先选择一个支持打开 URL/内容 ID 的已注册服务，再将链接或 ID 直接交给该服务处理。不经过自动 URL 匹配或搜索。 |
| 搜索导出文件 | 在已配置的导出目录及其服务子目录中，按文件名、标题、集数或服务名搜索。选中文件后进入既有的导出导入流程。 |
| 搜索密钥库 | 输入 KID、密钥、密钥对、片名或服务名时实时展示匹配的本地密钥。点击“搜索密钥库”动作可打开完整搜索页查看更多结果或显式触发远程查询。 |
| 添加密钥 | 打开既有的手动添加密钥编辑器。可先输入 `KID:KEY` 预填，也可留空直接打开；在编辑器内选定服务并核对本地/远程写入目标后再提交。 |
| 搜索设置 | 按页面标签、别名、说明和稳定配置键搜索设置项与管理动作。选中后会打开所属页面并高亮对应项；共享轨道偏好会先询问要编辑哪个服务。 |

所选模式会持续显示在输入框左侧，因此显式选择绝不会被静默改写。例如在**搜索设置**中输入一个 URL，只会把它当作设置关键词来搜，而不会打开对应服务。**服务内搜索**会记住上次选定的服务，再次选择该模式即可更换。**使用指定服务打开**会独立记住自己的已选服务；选定后左侧控件会显示**打开 · 服务名称**（英文为 `open · Service name`），完整模式名与服务名可在悬停提示中查看。

### 自动模式下的服务内搜索建议

在自动模式下，可以在片名关键词之前或之后附上服务名称、ID、已声明别名或简短标签。例如输入 `The Tourist bbc`、`The Tourist iP` 或 `BBC iPlayer The Tourist`，都会给出**在 BBC iPlayer 搜索“The Tourist”**（保留原始大小写）。选中该候选项会直接走与**服务内搜索**相同的流程，省去弹出服务选择器的步骤。

匹配以空白分隔的完整词为单位，不区分大小写，且支持多词服务名。在首尾两端均采用最长匹配优先原则：例如 `The Tourist BBC iPlayer` 会剥离完整的 `BBC iPlayer`，而不会只剥离其中较短的重叠词。不完整名称、夹在片名中间的词，以及未注册或不支持搜索的服务都不会触发这类建议。如果只输入了服务名而没有剩余关键词，则保留普通的打开服务行为。若名称或标签存在歧义，每种解释都会作为独立候选项列出，UniDL 不会替你静默决定服务。

候选项会清晰标明目标服务和剥离后精确的剩余关键词。输入过程仅在本地生成建议；点击候选项可直接搜索，或按 Enter 将焦点移至结果列表后再按 Enter 确认所选候选。URL、导出路径和 KID/密钥路由仍保持更高优先级。自动推断的输入长度上限为 4,096 个字符，更长的输入请使用显式搜索模式。

只有声明支持搜索的已注册服务会被纳入推断，包括在经典首页网格中隐藏的服务。这些建议受自动结果类型中的**服务内搜索**复选框控制；取消勾选后，显式模式仍可正常使用。其他自动结果、JustWatch 以及通用服务选择器仍会以完整原始输入保持可用。显式搜索模式绝不会自动剥离服务词。

使用该快捷项不会改动自动模式本身、完整输入文本或已记住的显式服务范围。返回操作遵循服务既有的页面导航逻辑，最终会回到同一个自动模式查询和选中状态。

在**使用指定服务打开**模式下，合法性校验完全归该服务自身的 URL/内容 ID 处理器所有。无论是纯数字 ID、区分大小写的 ID、未配置自动匹配规则的链接，还是形似 KID 的 ID，都会原样传给显式选定的服务，UniDL 不会将其改道至密钥库、JustWatch、其他服务或导出导入。选择该模式与服务本身不会触发提交，需要按 Enter 或点击**前往**（Go）继续；如果尚未选定服务就直接提交，选完服务后会自动完成这次已确认的提交动作。取消服务选择器则保持输入内容不变。

你也可以直接粘贴带参数的斜杠命令后按 Enter：

- `/service BBC`
- `/justwatch The Tourist`
- `/catalog The Tourist`
- `/url https://example.com/watch/123`
- `/open 12345678`
- `/exports The Tourist`
- `/vault 0123456789abcdef0123456789abcdef`
- `/addkeys`（可选后接一对 `KID:KEY`）
- `/settings default_subtitle`
- `/schedule`（打开定时下载）
- `/radar`（打开即将上映雷达）
- `/auto BBC`

这些斜杠别名为稳定的英文命令，而可见菜单和帮助文本随界面语言切换。输入命令会切换模式并填入查询内容，再次按 Enter 即可提交（需要时先选择服务）。

## 显式操作与安全边界

输入文字仅根据已注册服务声明、设置元数据和已索引的导出文件元数据在本地构建建议。导出目录扫描在常规自动查询，或选择/刷新导出搜索模式时于后台执行。输入过程绝不会登录服务、拉取 manifest、访问 JustWatch 或查询远程密钥库。设置搜索仅索引标签、说明和配置键，绝不索引已保存的配置值、密码或令牌。

设置搜索涵盖各管理页自有操作（如**注册服务**、**主页显示的服务**和**导出清单类型**），以及文件与命名、JustWatch 搜索、代理与 VPN、DRM 与密钥库、下载行为和界面与诊断下的全部配置行。当前页面标签与旧版设置名称指向同一条结果，不会出现重复项。即使选择了其他界面语言，直接输入英文标签同样可以搜到对应设置。

排序上，精确标签与稳定配置键排在最前，其次是别名与名称匹配，仅命中说明文本的结果排在最后。大小写、空格、下划线和标点不影响匹配：例如输入 `Register service` 可命中**注册服务**，输入 `Release suffix` 可命中文件与命名中的对应行。点击结果会在既有管理页中定位并高亮该条目，但不会直接注册服务包、切换开关、打开目录、发起网络请求或弹出编辑器。需要按 Enter 或使用页面原有控件确认才会执行。按返回键会回到原先的首页查询、模式和结果选中项；若打开了编辑器，返回会先回到所属管理页。

遇到模糊或存在歧义的服务查询时，按 Enter 会先将焦点移至结果列表，由你用鼠标或方向键加 Enter 明确挑选，UniDL 不会仅仅因为某服务存在就直接打开第一项。受支持的 URL 仅在恰好匹配唯一服务时直接打开，多个匹配项则必须由用户选择。原始 URL（包括区分大小写的签名参数）会原封不动传递。

自动模式和**搜索密钥库**在输入时即直接展示本地密钥结果，无需跳转新页面。自动模式最多预览 3 条匹配的本地记录；密钥库模式列出最多 40 条并提供常规的**加载更多**控件。空输入不会暴露整个密钥库。该过程遵循与完整密钥库搜索相同的“搜索密钥库”目标选择和仅本地后端规则；若未选择任何密钥库或仅选了远程目标，则不会查询本地数据库。

连续快速输入会做 100 ms 防抖合并，本地 SQLite 查询在 UI 线程之外执行。一旦查询词或目标选择改变，旧结果会立即清空，迟到的异步结果绝不会覆盖当前查询。点击某条密钥结果，或高亮后按 Enter / `ctrl+y`，即可按既有剪贴板机制复制完整的 `KID:KEY` 密钥对。在密钥库模式下按 `ctrl+r` 可在数据库变动后刷新当前查询。

**搜索密钥库**动作仍然可以打开完整的密钥库搜索页。远程查询保留原有的**搜索远程密钥库**显式操作以及后端/服务选择。打字输入、展示本地结果和剪贴板复制绝不会触发远程查询、许可证请求或密钥库写入。

**添加密钥**是独立的显式写入操作，不会因为你在自动模式或搜索密钥库中粘贴了密钥而自动触发。选择该模式或键入密钥对不会写入任何数据。按 Enter 或点击**前往**会打开既有编辑器，其目标选择器、输入校验、冲突确认和写入报告保持不变。本地密钥库和已启用的可写远程密钥库遵循原有写入策略：远程手动写入必须同时开启 `remote_vault` 和 `remote_vault_manual_add`，只读或禁止推送的后端无法接收密钥。请务必在编辑器中核对服务和目标后再保存。

## 导出导入与导航

在自动模式下输入常规文本时，也会同步搜索本地导出文件的文件名、标题、集数和服务名，无需切换模式即可看到匹配文件。自动模式最多预览 3 个文件，点击**搜索导出文件**可带着同一查询查看全部匹配项。首次常规查询会在后台启动扫描，后续输入直接筛选内存索引，返回首页时自动刷新。URL、KID/密钥查询以及显式服务搜索模式保留原有路由，空输入的自动模式依然不展示文件列表。

选择**搜索导出文件**（或输入 `/exports`）可按时间倒序浏览已配置导出目录中的文件。空查询显示最近文件；输入文字会筛选文件名、服务名/ID 以及批量文件内部的标题和集数。扫描在后台运行，输入时只过滤缓存元数据而不反复读取磁盘文件。密钥、鉴权请求头和 manifest URL 不会进入搜索索引。新增或改动文件后，按 `ctrl+r` 或重新选择该模式即可刷新。

点击结果或用方向键加 Enter 即可选中。焦点在输入框时首次按 Enter 会先聚焦到结果列表；单纯扫描或筛选绝不会触发下载。单标题导出文件会直接进入既有交付流程；多标题文件会打开既有标题选择器，供你挑选单条、多条或全部内容后再继续。返回键会退回同一个导出搜索页面及原查询词。选中文件时会重新读取磁盘源文件，若文件已被删除或无法读取，则报错且不启动导入。现有的导出目录导入页以及原生/第三方导出导入规则均保持不变。

在**自动**或**打开链接**模式下，可以直接粘贴一个已存在的 UniDL 导出 JSON 文件路径并按 Enter。支持以 `/` 开头的绝对路径、包含空格的路径以及首尾带引号的路径。粘贴操作绝不会弹出斜杠命令菜单；如果是手动输入绝对路径，按 Escape 关闭斜杠菜单后，保留的 `/` 后面可继续输入路径。单标题导出走常规交付流程，多标题导出则打开既有条目选择器，而不会擅自下载其中某一集。

从服务页、搜索页、设置页或导入页返回时，会回到这个实验版搜索首页，并完整保留当前的模式、输入内容和结果选中状态。后台本地刷新期间，已知的就绪/导入状态以及同查询词的搜索结果会保持可见，不会闪回成“加载中”占位符。数据未变化时保留原有列表与布局，有变化时再在就绪后替换快照。一旦修改查询词、密钥库目标或源目录，来自旧来源的结果会立即清空。主题、界面语言、设备与窗口尺寸的真实变更仍正常刷新界面。在首页内部，按 `ctrl+b` 会依次将焦点从结果移回输入框、清空查询、最后将非自动模式切回自动模式。右上角的**搜索**按钮和 `ctrl+f` 与经典首页一样打开全局搜索页，不会只是静默聚焦可能已处于焦点的输入框；返回后仍回到同一首页模式与查询。点击大输入框即可使其聚焦。原有的设置、命令面板和退出控件全部可用。

界面偏好与自动结果类型偏好会被持久化保存；搜索文本、已选服务范围和结果光标仅作为当前会话状态，不会生成新的持久化搜索历史。
