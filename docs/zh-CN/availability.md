# 上架情况查询

[English](../availability.md) | [简体中文](availability.md)

全局搜索能够回答你在挑选服务之前最先面对的问题：我关注的地区里，哪些平台上线了这部作品？查询通过 JustWatch 获取数据，再把各流媒体平台映射回 `unidl` 中已注册的原生服务。

## 使用方法

1. 在主页点击搜索或按 `ctrl+f`。
2. 输入电影或剧集名称。
3. 打开**上架情况（Availability）**分组下的**哪里可以看（Where can I watch this）**。
4. 选择匹配的作品。
5. 打开标有已安装服务的播放条目。

如果对应服务支持站内搜索，`unidl` 打开它时会自动预填作品标题；否则会进入该服务菜单并请你提供其专属 URL 或内容标识符。仅限实体光盘的条目以及没有对应服务的平台仍会展示，但无法直接打开。

频道附加订阅（Channel add-on）以实际承载播放的宿主平台为准。映射器会先检查分销商/宿主平台前缀，再看内容品牌，且仅打开已注册的宿主服务。如果宿主平台未注册，该行会显示无对应服务，而不会错误回退到内容品牌的独立服务——避免把第三方频道附加包当成原厂独立应用。

上架条目先按地区分组，再按订阅、免费、含广告免费、租赁和购买分类展示。剧集条目还会列出平台提供的季数信息。按 `ctrl+y` 可复制当前高亮条目的链接（若无则回退复制该作品的 JustWatch 页面链接）。按 `p` 可开关右侧 2:3 海报预览检查器，按 `t` 可直接为高亮作品创建定时下载任务（详见[定时下载](scheduled-downloads.md)）。

## 地区设置

在作品列表或上架详情页按 `ctrl+r` 即可选择查询地区。地区选择器支持关键词筛选、按 `space` 勾选以及按 `enter` 确认；在选择器内再按 `ctrl+r` 会恢复内置默认地区列表。

同一配置也可在全局设置中编辑：

```text
justwatch_regions = US,GB,CA,AU,JP
```

该项保存在 `<paths.home>/settings.json` 中，而不是 `unidl.yaml`，因为它属于交互式浏览偏好。地区代码采用 ISO 国家代码，会自动去重并保留原有顺序；留空或全部无效时会回退到内置默认值。

每个地区对应一次独立的网络请求。列表越短返回越快，且单个地区查询失败只会报错在该地区下，不会丢弃其他地区的结果。

## 查询结果的含义

JustWatch 上架信息属于片源发现数据，而不是播放权益校验。查到某条上架记录并不代表你的账号等级、所在地区或设备一定能播放，且平台到服务的映射本质上是尽力匹配。真正选定服务后，该服务仍会执行常规的登录、地区与播放权限校验。

每次敲击搜索字符时都不会触发查询。全局搜索只提供入口选项，只有在你主动选中该操作后才会发起网络请求。

## 验证方式

运行项目测试套件，检查离线映射与 UI 行为：

```bash
python -m pytest -q
```

如需做在线联调，可配置一组地区列表，逐项核对各平台条目是否解析到预期的已注册服务。请牢记上架查询仅提供发现数据，所选服务仍会自行执行账号权益与地区校验。
